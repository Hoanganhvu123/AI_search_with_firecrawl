FireStation Architecture

How Quick Search and Deep Research work end-to-end — from user query to streamed answer.

Feature Overview

Quick Search

Fast web search → AI-synthesized answer via SSE streaming.

  • Firecrawl v2 /search (web + news)
  • 5-col source cards with favicon + char count
  • LLM answer via FreeLLMAPI proxy
  • Follow-up question generation
  • SQLite history persistence

Deep Research

Multi-step autonomous research with LangGraph orchestration.

  • 6-phase state machine
  • Multi-query planning + execution
  • Source scraping + content analysis
  • Progress sidebar with step tracker
  • Timer + source counter

Quick Search — End-to-End Flow
